# The Allies Manifesto

## Deployment

### Local environment

#### Prerequisites

1. Install Jekyll, Ruby and Bundler according to [this doc](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/testing-your-github-pages-site-locally-with-jekyll#prerequisites).
2. Run `bundle install`. To update Gemfile.lock, run `bundle update`.

Run:

```zsh
bundle exec jekyll serve --baseurl=""
```

The website is served at: http://localhost:4000
